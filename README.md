# Retail Store Sales Dashboard

An interactive **Power BI dashboard** created from a retail store dataset to analyze sales performance, customer transactions, product categories, payment methods, and branch performance.

The project covers the complete process from **data cleaning and preparation to analysis and visualization**. The original dataset contained 1,030 records, which were cleaned and reduced to 1,000 valid transactions by addressing duplicate records and formatting inconsistencies.

### Tools Used

* **Open Refine** – Data cleaning, pivot tables, and preliminary analysis
* **Power BI** – Data visualization and interactive dashboard development

### Key Areas Analyzed

* Total sales and transaction performance
* Sales by product category and product
* Quantity sold
* Store branch performance
* Payment method distribution
* Customer transaction patterns
* Sales trends over time

This project demonstrates my foundational skills in **data cleaning, exploratory analysis, Excel, and Power BI**, with a focus on turning raw retail data into clear and useful business insights.
